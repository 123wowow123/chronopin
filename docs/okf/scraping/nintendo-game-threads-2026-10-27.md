# Nintendo game release threads — 2026-10-27

Requested scope: add Nintendo game pins and series threads on production. This catalog covers 89 selected releases in 32 series and spinoffs; it is not an exhaustive all-time Nintendo software bibliography.

78 release pins were created under @GameDesk. Eleven existing pins were reused, preserving their authors, source URLs and release-date confidence. Four unrelated review successors were reconnected to their former unaffected review ancestors. No application deployment was performed.

## Evidence and dates

Switch and Switch 2 dates, platform information, content ratings and gallery artwork were read from opened Nintendo store pages. Retired U.S. 3DS, Wii, Wii U, GameCube and GBA listings were supplemented by opened Nintendo Life release specifications; surviving Nintendo UK archives provide additional references and some artwork. Paired Pokémon releases have independently opened references for both versions. Bayonetta 2, Bayonetta 3 and Emio use explicitly identified European edition milestones from Nintendo UK.

Remakes and ports retain the release date of the edition named in the pin. Threads follow release history, not fictional chronology; Tears of the Kingdom responds directly to Breath of the Wild. Existing upcoming Ocarina of Time and Metroid Ravenous pins remain scheduled. Pokémon Winds/Waves retains its explicitly estimated November 2027 day because Nintendo confirms only the year 2027. Research/check dates are not used as source publication dates.

Every catalog game has 2–3 sourced competing products (224 rows total), ranked editorially from opened product or review specifications. No selected rival edition postdates the pin. Platform profiles use native PinGameInfo keys for 73 Switch / Switch 2 pins. These researched edition profiles are protected as curated readings so automatic original-game Wikidata matches cannot replace remake platform information; existing hand-entered profiles were preserved. Unsupported legacy platform keys were not invented.

## Thread presentation

The current application walks descendants by the same author. Because the existing authors must be preserved, each series root also carries a complete **Series releases** index linking all its native pin pages, including cross-author entries. The parent relationships still form the researched series threads. This avoids changing authors or requiring an application deployment.

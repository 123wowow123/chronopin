# Playbooks

* [Catch up and retry](catch-up-and-retry.md) - Backfill wikis, retry failed links, fix stale summaries with npm run wiki:sync
* [Lint the wikis](lint-the-wikis.md) - Check conformance, re-read stale links, prune orphans, catch poor wikis and flag contradictions with npm run okf:lint
* [Without API credit](without-api-credit.md) - Export the Claude jobs, do them in a Claude Code session, apply the answers
* [Export an OKF bundle](export-a-bundle.md) - Write pins and their link wikis out as a standard OKF bundle
* [Scrape without credit](scrape-without-credit.md) - Do the scraper's Claude stages in a Claude Code session and save through the real API

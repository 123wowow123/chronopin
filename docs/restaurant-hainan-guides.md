## Local import and validation

```sh
npx tsx scripts/restaurants/importGuide.ts --file docs/restaurant-hainan-guides.json
npx tsx scripts/restaurants/importGuide.ts --file docs/restaurant-hainan-guides.json --apply
```

These default to localhost and use `CHRONOPIN_ADMIN_TOKEN` from the environment. Dry run first; apply verifies public galleries and creates missing pin/content/special/gallery records through the APIs while preserving existing edits. Production use requires separate consent.

Saved local pin IDs 7494–7500 (database-specific). Readback verified all seven content profiles, the special venue and all 13 gallery links. Browser checks passed for both cities and all four requested views, seven pin pages with menus and decoded images, 17-city west-to-east navigation, the Hainan redirect and mobile layouts, with zero browser errors.

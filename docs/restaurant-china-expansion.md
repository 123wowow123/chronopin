## API import and validation

Use an existing admin token in CHRONOPIN_ADMIN_TOKEN, never in the snapshot or command arguments:

```sh
npx tsx scripts/restaurants/importGuide.ts --file docs/restaurant-china-expansion.json
npx tsx scripts/restaurants/importGuide.ts --file docs/restaurant-china-expansion.json --apply
```

The importer defaults to localhost and dry run. It preflights city support and verifies every public image hash, dimensions and decoding before applying; existing editorial records are preserved and photo attachment is idempotent. An approved production import would add `--url https://www.chronopin.com` after an approved city-registration deployment.

Local import created pins 7467–7480; IDs are not portable between databases. A subsequent dry run preserved all 14 existing pins/content profiles. All 38 Azure blobs passed public hash, dimensions and decode verification before attachment.

Empty-view links fall back to populated content. Before service, the Chongqing and Shenzhen offers remained visible and showed the next local start (12:00 and 16:00 GMT+8 respectively).

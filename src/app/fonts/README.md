IBM Plex Sans is bundled locally to avoid the Turbopack 16.3.6 Google font
import-map failure seen in GitHub Actions run 40422151762.

- Source: https://github.com/google/fonts/tree/main/ofl/ibmplexsans
- Download: https://raw.githubusercontent.com/google/fonts/main/ofl/ibmplexsans/IBMPlexSans%5Bwdth%2Cwght%5D.ttf
- Retrieved: 2026-10-26
- Converted losslessly from the upstream variable TTF to WOFF2 with FontTools.
- Includes the upstream glyph set and weight/width axes; the app uses normal
  width and weights 400–600.
- License: SIL Open Font License 1.1, reproduced in `IBMPlexSans-OFL.txt`.
